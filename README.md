# Try Cat & Try Fish

I am experimenting with AI assisted coding and I've practically vibe-coded this app, with minimal code reviews. Use at your own risk.

## Deployment

Pushes to `main` are tested, built, and deployed to GitHub Pages by
`.github/workflows/deploy-pages.yml`. In the repository settings, set the Pages
source to **GitHub Actions**. The published site is available at
https://grantjames.github.io/trycat/.
